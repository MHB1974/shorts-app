쇼츠추천 · 시행일 2026년 11월 19일

쇼츠추천(이하 “이 도구”)은 유튜브 채널 운영자 본인이 자신의 컴퓨터에서만 사용하는 개인용 영상 제작 도구입니다. 이 도구가 Google 사용자 정보를 어떻게 다루는지 아래와 같이 알려드립니다.

1. 사용하는 정보

  • Google 로그인으로 받는 유튜브 업로드 권한(youtube.upload)과 채널 기본 정보 읽기 권한(youtube.readonly)만 사용합니다.
  • 채널 기본 정보는 영상을 올릴 채널 이름을 화면에 보여 주는 데만 씁니다.

2. 사용 목적

  • 운영자가 만든 영상을 운영자 본인의 유튜브 채널에 업로드하기 위해서만 사용합니다.
  • 광고, 분석, 판매 등 다른 목적으로는 사용하지 않습니다.

3. 저장과 보관

  • 로그인 후 받은 인증 정보(토큰)는 운영자 컴퓨터 안에만 저장되며, 외부 서버로 보내지 않습니다.
  • 운영자가 연결을 해제하거나 도구를 삭제하면 함께 삭제됩니다.

4. 제3자 제공

Google 사용자 정보를 다른 사람이나 회사에 제공·판매·공유하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 도구가 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

6. 권한 철회

언제든지 Google 계정의 서드파티 액세스 관리에서 “쇼츠추천”의 접근 권한을 삭제할 수 있습니다.
